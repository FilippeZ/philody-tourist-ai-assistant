Αρχιτεκτονική 4 Πυλώνων

Απόλυτος διαχωρισμός πιθανοτικής επικοινωνίας και αυστηρής προσδιοριστικής λογικής.

📚

Tourism RAG Pipeline

Εμπλουτισμένα chunks με πλήρη metadata (ωράρια, διάρκεια, προσβασιμότητα). 3-Tier fallback embeddings με μηδενική ανοχή σε ψευδαισθήσεις.

⚙️

Feasibility Engine

Μαθηματική εγγύηση δρομολογίου. Υπολογισμός αποστάσεων με τον τύπο Haversine και έλεγχος ωραρίων t_arrival + t_visit ≤ t_closing.

Weather Replanning

Live ενσωμάτωση OpenWeather API με Resilience Fallback. Αυτόματος αποκλεισμός εξωτερικών χώρων και αντικατάσταση με indoor μουσεία σε βροχή.

Wearable IoT Edge

Σύνδεση με Smartwatch/Bracelet. Αυτόματη ένεση στάσης ανάπαυσης σε έντονη κόπωση, haptic δονήσεις και bite-sized κάρτες για τον καρπό.
